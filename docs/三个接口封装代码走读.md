## 一、路由总览（processRequest 函数）

```
  HP-Socket HTTP 请求
        │
        ▼
  OnMessageComplete() → commitNoWait(线程池)
        │
        ▼
  processRequest(pSender, dwConnID, st)    ← st = {method, path, queryString, body}
        │
        ├── 路由1: /InsertWaveInfo   → 入队 TaskQueue，异步解析
        ├── 路由2: /BindingLatticePort → Query参数→写入 QMap
        ├── 路由3: /InsertWaveIn    → 遍历波次→逐条 S7 下发 PLC
        ├── 路由4: /CancelWave       → 三级校验→清理波次
        └── 未知 → 404
```

## 二、接口一：退货任务格口分配（InsertWaveInfo）

### 2.1 路由分发代码

```cpp
// ═══ 路由1: WMS波次数据推送 ═══
// 报文: POST /api/DispatchSortingCommand/InsertWaveInfo
if (st.path == "/api/DispatchSortingCommand/InsertWaveInfo" && st.method == "POST")
{
    // ── 水位保护：队列最大排队 5 个波次 ──
    if (m_pQueue->size() >= MAX_TASK_QUEUE)                    // MAX_TASK_QUEUE = 5
    {
        HTTP_WARN("队列已满 拒绝入队 queue=%d", m_pQueue->size());
        sendJsonResponse(pSender, dwConnID,
            errResponse("服务器繁忙", "503"), 503);             // → WMS: 503 稍后重试
        emit logMessage("[WMS] 队列已满，拒绝入队 返回503", true);
    }

    // ── Body 为空校验 ──
    else if (st.body.isEmpty())
    {
        HTTP_WARN("Body为空 拒绝");
        sendJsonResponse(pSender, dwConnID,
            errResponse("Body为空", "400"));                   // → WMS: 400 参数错误
        emit logMessage("[WMS] Body为空", true);
    }

    // ── 正常入队：不解析 JSON，立即返回 ──
    else
    {
        WaveTask task;
        task.rawBody  = st.body;                                // 拷贝原始 JSON
        task.recvTime = QDateTime::currentMSecsSinceEpoch();    // 记录接收时间
        m_pQueue->push(task);                                   // 非阻塞入队

        sendJsonResponse(pSender, dwConnID,
            okResponse("accepted"));                            // → WMS: 200 OK

        HTTP_INFO("InsertWaveInfo 入队 len=%d queue=%d elapsed=%lldms",
            st.body.size(), m_pQueue->size(), reqTimer.elapsed());
        emit logMessage(QString("[WMS] InsertWaveInfo 入队 size=%1 queue=%2")
            .arg(st.body.size()).arg(m_pQueue->size()));
    }
    return;
}
```

### 2.2 数据流

```
  WMS POST JSON
      │
      ▼
  路由分支 → TaskQueue::push() → 200 OK (<1ms)
      │
      ▼ (ParseWorker 后台线程，低优先级)
  QJsonDocument::fromJson(rawBody)
      │
      ├── 提取 orderCode, orderQty
      ├── 遍历 items[]
      │   └── 构建 QMap<inco, GridEntry{gridNum, gridType, gridCount}>
      └── DoubleBuffer::prepareSwap(newMap)
           └── std::atomic::exchange → 无锁写入
```

### 2.3 响应格式

```json
// 成功
{ "code": "200", "message": "accepted", "sentTime": "2026-07-22 15:30:00.000" }

// 队列满
{ "code": "503", "message": "服务器繁忙", "sentTime": "..." }

// Body 空
{ "code": "400", "message": "Body为空", "sentTime": "..." }
```

## 三、接口二：格口容器绑定（BindingLatticePort）

### 3.1 路由分发代码

```cpp
// ═══ 路由2: 格口容器绑定 ═══
// 报文: POST /api/DispatchSortingCommand/BindingLatticePort?latticehole=00001&boxcode=fDD03
if (st.path == "/api/DispatchSortingCommand/BindingLatticePort" && st.method == "POST")
{
    // ── 优先从 URL Query 参数解析（WMS 文档标准格式）──
    QUrlQuery q(st.queryString);
    QString latticehole = q.queryItemValue("latticehole").trimmed();
    QString boxcode     = q.queryItemValue("boxcode").trimmed();

    // ── 如果 Query 为空，兜底从 JSON Body 解析 ──
    if (latticehole.isEmpty() || boxcode.isEmpty())
    {
        QJsonDocument d = QJsonDocument::fromJson(st.body);
        QJsonObject obj = d.object();
        latticehole = obj["latticehole"].toString().trimmed();
        boxcode     = obj["boxcode"].toString().trimmed();
    }

    QJsonObject result = handleBindingLatticePort(latticehole, boxcode);
    sendJsonResponse(pSender, dwConnID, result);

    HTTP_LOG_INFO("BindingLatticePort latticehole=%s boxcode=%s elapsed=%lldms",
        latticehole.toLocal8Bit().data(), boxcode.toLocal8Bit().data(), reqTimer.elapsed());
    return;
}
```

### 3.2 Handler 代码

```cpp
QJsonObject HttpServer::handleBindingLatticePort(
    const QString& latticehole, const QString& boxcode)
{
    // ── 参数空校验 ──
    if (boxcode.isEmpty() || latticehole.isEmpty())
    {
        HTTP_LOG_WARN("BindingLatticePort 参数缺失 boxcode=%s latticehole=%s",
            boxcode.toLocal8Bit().data(), latticehole.toLocal8Bit().data());
        emit logMessage(QString("[容器绑定] 参数缺失 boxcode=%1 latticehole=%2")
            .arg(boxcode).arg(latticehole), true);
        return errResponse("参数缺失", "400");
    }

    // ── 线程安全写入 QMap ──
    {
        std::lock_guard<std::mutex> lock(m_containerMutex);    // RAII 自动锁
        m_containerBindings[latticehole] = boxcode;            // 格口号 → 容器号
    }                                                          // 自动解锁

    // ── 双写日志（文件 + UI）──
    HTTP_LOG_INFO("容器绑定成功 latticehole=%s → boxcode=%s total=%d",
        latticehole.toLocal8Bit().data(), boxcode.toLocal8Bit().data(),
        (int)m_containerBindings.size());
    emit logMessage(QString("[容器绑定] 格口%1 → 容器%2 (共%3条)")
        .arg(latticehole).arg(boxcode).arg(m_containerBindings.size()));

    // ── 特殊响应格式：code 为 Int 类型，Message 首字母大写 ──
    QJsonObject r;
    r["code"]    = 200;
    r["Message"] = "收到信息";
    return r;
}
```

## 四、接口三：波次执行触发（InsertWaveIn）

### 4.1 路由分发代码

```cpp
// ═══ 路由3: 波次执行触发 ═══
// 报文: POST /api/DispatchSortingCommand/InsertWaveIn
// WMS 确认波次数据已下发完毕，WCS 遍历所有条码，通过 S7 向 PLC 发送分拣指令
if (st.path == "/api/DispatchSortingCommand/InsertWaveIn" && st.method == "POST")
{
    QJsonDocument d = QJsonDocument::fromJson(st.body);
    QJsonObject result = handleInsertWaveIn(d.object());
    sendJsonResponse(pSender, dwConnID, result);
    HTTP_LOG_INFO("InsertWaveIn elapsed=%lldms", reqTimer.elapsed());
    return;
}
```

### 4.2 Handler 代码（核心批量执行逻辑）

```cpp
QJsonObject HttpServer::handleInsertWaveIn(const QJsonObject& req)
{
    QString orderCode = req["orderCode"].toString().trimmed();

    // ═══ 第一级：参数校验 ═══
    if (orderCode.isEmpty())
    {
        HTTP_LOG_WARN("InsertWaveIn 缺少orderCode");
        emit logMessage("[InsertWaveIn] 缺少orderCode", true);
        return errResponse("缺少orderCode", "400");
    }

    // ═══ 第二级：波次匹配校验 ═══
    if (!m_pWaveMgr || m_pWaveMgr->orderCode() != orderCode)
    {
        HTTP_LOG_WARN("InsertWaveIn 波次不匹配 req=%s current=%s",
            orderCode.toLocal8Bit().data(),
            m_pWaveMgr ? m_pWaveMgr->orderCode().toLocal8Bit().data() : "null");
        emit logMessage(QString("[InsertWaveIn] 波次不匹配或不存在 req=%1")
            .arg(orderCode), true);
        return errResponse("波次不存在", "404");
    }

    // ═══ 第三级：PLC 就绪检查 ═══
    if (!m_pPlcMgr || !m_pPlcMgr->isRunning())
    {
        HTTP_LOG_WARN("InsertWaveIn PLC服务未运行");
        emit logMessage("[InsertWaveIn] PLC服务未运行", true);
        return errResponse("PLC服务未就绪", "503");
    }

    // ═══ 获取波次全部条码 ═══
    QStringList allCodes = m_pWaveMgr->allCodes();
    int totalCount = allCodes.size();
    int sendOk = 0, sendFail = 0;

    HTTP_LOG_INFO("InsertWaveIn 开始执行 orderCode=%s total=%d",
        orderCode.toLocal8Bit().data(), totalCount);
    emit logMessage(QString("[InsertWaveIn] 开始执行 orderCode=%1 共%2条")
        .arg(orderCode).arg(totalCount));

    // 重置限流警告集合（新波次开始）
    { std::lock_guard<std::mutex> lock(m_warnMutex);
      m_warnedPlcFailCodes.clear(); }

    // ═══ 遍历所有条码，逐条 S7 发送 PLC ═══
    for (const QString& code : allCodes)
    {
        GridEntry e = m_pWaveMgr->getGrid(code);        // 从 DoubleBuffer 查格口
        if (e.gridNum.isEmpty()) { sendFail++; continue; }

        // 解析格口列表（支持 "122,133,144" 多格口逗号分隔）
        std::vector<int> vecGrid;
        QString g = e.gridNum;
        if (g.contains(',')) g = g.split(',').first().trimmed();
        QStringList gridList = g.split(',');
        for (const QString& gs : gridList) {
            bool ok; int gn = gs.trimmed().toInt(&ok);
            if (ok) vecGrid.push_back(gn);
        }
        if (vecGrid.empty()) { sendFail++; continue; }

        bool sent = m_pPlcMgr->sendCodeInfo(code, vecGrid, 1);  // S7 DBWrite
        if (sent) {
            sendOk++;
            LIFE_STAGE_PLC_SEND(code, g, "1");      // 生命周期追踪
        } else {
            sendFail++;
            // 限流：每个条码每波次只警告一次，避免日志洪水
            bool firstWarn = false;
            {
                std::lock_guard<std::mutex> lock(m_warnMutex);
                if (!m_warnedPlcFailCodes.contains(code))
                    { m_warnedPlcFailCodes.insert(code); firstWarn = true; }
            }
            if (firstWarn) {
                HTTP_LOG_WARN("InsertWaveIn PLC发送失败 code=%s err=%s",
                    code.toLocal8Bit().data(),
                    m_pPlcMgr->lastError().toLocal8Bit().data());
                LIFE_STAGE_PLC_SEND_FAIL(code);
            }
        }
    }

    emit logMessage(QString("[InsertWaveIn] 完成 orderCode=%1 成功=%2 失败=%3")
        .arg(orderCode).arg(sendOk).arg(sendFail));

    // ── 返回执行统计 ──
    QJsonObject r;
    r["code"]       = 200;
    r["Message"]    = "收到信息";
    r["totalCount"] = totalCount;
    r["sendOk"]     = sendOk;
    r["sendFail"]   = sendFail;
    return r;
}
```

### 4.3 数据流

```
  WMS POST {orderCode: "PB2025..."}
      │
      ▼
  校验 orderCode → 波次匹配 → PLC 就绪
      │
      ▼
  WaveManager::allCodes() → QStringList ["A001","A002",...]
      │
      ▼
  for (code : allCodes) {
      DoubleBuffer::get(code) → GridEntry
      PlcManager::sendCodeInfo(code, vecGrid, 1) → S7 DBWrite → PLC
  }
      │
      ▼
  返回 {totalCount, sendOk, sendFail}
```

```json

  "Message": "收到信息",
  "totalCount": 5000,
  "sendOk": 4980,
  "sendFail": 20
}
```

### 5.2 sendJsonResponse（底层 HTTP 发送）

```cpp
void HttpServer::sendJsonResponse(IHttpServer* pSender, CONNID dwConnID,
                                   const QJsonObject& json, USHORT status)
{
    QByteArray d = QJsonDocument(json).toJson(QJsonDocument::Compact);
    THeader h[1];                                 // HP-Socket 响应头
    h[0].name  = "Content-Type";
    h[0].value = "application/json; charset=UTF-8";
    pSender->SendResponse(dwConnID, status,       // HP-Socket 线程安全
        nullptr, h, 1, (const BYTE*)d.constData(), d.length());
}
```

## 六、线程安全保护

| 数据 | 保护 | 三个接口中的使用 |
|---|---|---|
| `m_connStates` | `m_connMutex` | `OnRequestLine`/`OnBody`/`OnMessageComplete` 中读连接状态 |
| `m_pQueue` | `QMutex + QWaitCondition` | InsertWaveInfo 入队 |
| `m_containerBindings` | `m_containerMutex` | BindingLatticePort 写入、CancelWave 清理 |
| `m_waveStatus` | `std::atomic<int>` | InsertWaveIn / CancelWave 状态查询（无锁） |
| `m_warnMutex` | `std::mutex` | InsertWaveIn 限流警告（防日志洪水） |
| `m_connMutex` | `std::mutex` | OnAccept/OnClose/OnMessageComplete |
