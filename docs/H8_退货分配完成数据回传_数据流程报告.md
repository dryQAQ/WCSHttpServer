## 4. 波次完成判定逻辑

### 4.1 判定函数

```cpp
// WaveManager.cpp 第157-172行
bool WaveManager::checkWaveCompleteLocked() const
{
    // 条件1: 全部SKU处理完毕
    int total = m_setCodeRecv.size();
    int done  = m_setCodeSorted.size() + m_setCodeException.size();
    if (total > 0 && done >= total)
        return true;

    // 条件2: 超时强制完结
    if (m_bSortingStarted && m_waveTimeoutMin > 0)
    {
        qint64 elapsed = m_waveStartTime.secsTo(QDateTime::currentDateTime());
        if (elapsed > m_waveTimeoutMin * 60)
            return true;
    }

    return false;
}
```

### 4.2 判定条件详解

| 条件 | 触发规则 | 配置项 | 默认值 |
|------|---------|--------|--------|
| **条件1: 全部处理完成** | `sorted + exception >= totalRecv` 且 `totalRecv > 0` | — | — |
| **条件2: 超时强制完结** | `elapsed > m_waveTimeoutMin × 60` 秒 | `WAVE_TIMEOUT_MIN_DEFAULT` | `0`（禁用） |

### 4.3 判定时机

- `markSorted()` 每次调用后在锁内执行检查
- `markException()` 每次调用后在锁内执行检查
- `isWaveComplete()` 外部查询接口（`/api/waveStatus` 等）

### 4.4 关键约束

- `total > 0` 确保波次已收到数据（至少一个 inco 被注册）
- 超时判定仅在 `m_waveTimeoutMin > 0` 时生效，默认 `0` 表示禁用超时
- 函数仅在持有 `m_lock` 时调用，保证数据一致性

## 5. 完成触发流程

### 5.1 markSorted() 触发流程

```cpp
// WaveManager.cpp 第37-86行
void WaveManager::markSorted(const QString& code)
{
    bool complete = false;
    bool alreadyReported = false;

    {
        std::unique_lock<std::mutex> lock(m_lock);

        // ── 快速路径：波次已回传，跳过所有检查 ──
        if (m_bReported.load(std::memory_order_relaxed))
        {
            m_setCodeSorted.insert(code);
            m_setCodeProcessing.remove(code);
            m_mapCodeRetry.remove(code);
            lock.unlock();
            emit codeMarked(code, true);
            return;
        }

        // ── 正常路径：记录状态 ──
        m_setCodeSorted.insert(code);
        m_setCodeProcessing.remove(code);
        m_mapCodeRetry.remove(code);

        // ── 首次分拣 → 发射波次开始信号 ──
        if (!m_bSortingStarted && !m_orderCode.isEmpty())
        {
            m_bSortingStarted = true;
            emit waveSortingStarted(m_orderCode);
            setState(WAVE_SORTING);
        }

        // ── 检查波次完成 ──
        complete = checkWaveCompleteLocked();
        if (complete)
        {
            // ★ 关键：exchange 在锁内执行，与 checkWaveCompleteLocked 原子化
            // 消除 TOCTOU 竞态
            alreadyReported = m_bReported.exchange(true);
        }
    }  // 锁释放

    emit codeMarked(code, true);
    if (complete && !alreadyReported)
    {
        // ★ 首次完成：发射回传信号
        emit waveReadyToReport(m_orderCode);
        setState(WAVE_COMPLETING);
    }
}
```

### 5.2 markException() 触发流程

```cpp
// WaveManager.cpp 第88-131行
void WaveManager::markException(const QString& code)
{
    bool complete = false;
    bool alreadyReported = false;

    {
        std::unique_lock<std::mutex> lock(m_lock);

        // ── 快速路径：波次已回传 ──
        if (m_bReported.load(std::memory_order_relaxed))
        {
            m_setCodeException.insert(code);
            m_setCodeProcessing.remove(code);
            int retry = m_mapCodeRetry.value(code, 0) + 1;
            m_mapCodeRetry[code] = retry;
            lock.unlock();
            emit codeMarked(code, false);
            return;
        }

        m_setCodeException.insert(code);
        m_setCodeProcessing.remove(code);
        int retry = m_mapCodeRetry.value(code, 0) + 1;
        m_mapCodeRetry[code] = retry;

        complete = checkWaveCompleteLocked();
        if (complete)
        {
            alreadyReported = m_bReported.exchange(true);
        }
    }

    emit codeMarked(code, false);
    if (complete && !alreadyReported)
    {
        emit waveReadyToReport(m_orderCode);
        setState(WAVE_COMPLETING);
    }
}
```

## 6. 异步回传机制

### 6.1 HttpClient 架构

```cpp
// HttpClient.h 第18-53行
class HttpClient : public QObject
{
    Q_OBJECT
public:
    void setUrl(const QString& url);
    void setAppkey(const QString& k);
    void setTimeout(int ms);

    void sendWaveComplete(const QString& orderCode, int sumLocation);

signals:
    void reportResult(const QString& orderCode, bool success, const QString& body);

private slots:
    void onReplyFinished();
    void onReplyTimeout();

private:
    QNetworkAccessManager* m_pNetworkMgr;  // ★ 成员变量，非栈变量
    QString m_url;
    QString m_appkey;
    int     m_timeoutMs = HTTP_TIMEOUT_MS;  // 2000ms

    struct PendingRequest {
        QNetworkReply* reply;
        QTimer*        timer;
        QString        orderCode;
        int            sumLocation;
    };
    QMap<QNetworkReply*, PendingRequest> m_pending;
};
```

### 6.2 回传请求流程

```cpp
// HttpClient.cpp 第33-75行
void HttpClient::sendWaveComplete(const QString& orderCode, int sumLocation)
{
    // 1. 构造请求体
    QJsonObject head;
    head["orderCode"]     = orderCode;
    head["orderType"]     = "02";
    head["sumLocation"]   = QString::number(sumLocation);
    head["operuserDate"]  = QDateTime::currentDateTime().toString("yyyy-MM-dd HH:mm:ss");
    head["operuserCode"]  = "admin";
    head["operuserName"]  = "管理员";

    QJsonObject req;
    req["head"] = head;
    QByteArray postData = QJsonDocument(req).toJson(QJsonDocument::Compact);

    // 2. 发起异步POST
    QUrl url(m_url);
    QNetworkRequest request(url);
    request.setHeader(QNetworkRequest::ContentTypeHeader, "application/json; charset=UTF-8");
    request.setRawHeader("AppKey", m_appkey.toUtf8());

    QNetworkReply* reply = m_pNetworkMgr->post(request, postData);

    // 3. 创建超时定时器
    QTimer* timer = new QTimer(this);
    timer->setSingleShot(true);
    timer->setInterval(m_timeoutMs);  // HTTP_TIMEOUT_MS = 2000ms

    // 4. 跟踪请求
    PendingRequest pr;
    pr.reply       = reply;
    pr.timer       = timer;
    pr.orderCode   = orderCode;
    pr.sumLocation = sumLocation;
    m_pending.insert(reply, pr);

    // 5. 连接信号（异步回调）
    connect(reply, &QNetworkReply::finished, this, &HttpClient::onReplyFinished);
    connect(timer, &QTimer::timeout, this, &HttpClient::onReplyTimeout);

    timer->start();
}
```

### 6.3 响应处理

```cpp
// HttpClient.cpp 第77-104行
void HttpClient::onReplyFinished()
{
    QNetworkReply* reply = qobject_cast<QNetworkReply*>(sender());
    auto it = m_pending.find(reply);

    PendingRequest& pr = it.value();
    if (pr.timer) { pr.timer->stop(); pr.timer->deleteLater(); pr.timer = nullptr; }

    QByteArray respBody = reply->readAll();
    int statusCode = reply->attribute(QNetworkRequest::HttpStatusCodeAttribute).toInt();
    reply->deleteLater();

    QJsonDocument doc = QJsonDocument::fromJson(respBody);
    bool success = doc.object()["success"].toBool(false);

    emit reportResult(pr.orderCode, success, QString::fromUtf8(respBody));
    m_pending.erase(it);
}
```

### 6.4 超时处理

```cpp
// HttpClient.cpp 第106-130行
void HttpClient::onReplyTimeout()
{
    QTimer* timer = qobject_cast<QTimer*>(sender());

    for (auto it = m_pending.begin(); it != m_pending.end(); ++it)
    {
        if (it->timer == timer)
        {
            PendingRequest& pr = it.value();
            if (pr.reply) { pr.reply->abort(); pr.reply->deleteLater(); }
            pr.timer->deleteLater();
            emit reportResult(pr.orderCode, false, QString());
            m_pending.erase(it);
            break;
        }
    }
}
```

### 6.5 生命周期管理

```cpp
// HttpClient.cpp 第22-31行 — 析构函数中清理
HttpClient::~HttpClient()
{
    for (auto it = m_pending.begin(); it != m_pending.end(); ++it)
    {
        if (it->timer)  { it->timer->stop(); delete it->timer; }
        if (it->reply)  { it->reply->abort(); it->reply->deleteLater(); }
    }
    m_pending.clear();
}
```

## 7. 并发安全分析

### 7.1 同步原语一览

| 组件 | 同步机制 | 保护范围 |
|------|---------|---------|
| `m_lock` | `std::mutex` | `m_setCodeRecv`, `m_setCodeSorted`, `m_setCodeException`, `m_setCodeProcessing`, `m_mapCodeRetry` |
| `m_bReported` | `std::atomic<bool>` | 防止重复回传（无锁原子操作） |
| `m_waveStatus` | `std::atomic<int>` | 状态机线程安全读写 |

### 7.2 TOCTOU 竞态修复

**问题场景**：在修复前，`m_bReported` 的检查和设置在锁外执行，存在 Time-of-Check-Time-of-Use 竞态。

```
修复前（存在竞态）:
  lock → checkWaveCompleteLocked() → unlock → m_bReported.exchange(true)
                                                      ↑
                                            ←→ 其他线程可能在此期间
                                                也通过检查，导致重复回传

修复后（原子化）:
  lock → checkWaveCompleteLocked() → m_bReported.exchange(true) → unlock
             ↑                          ↑
             └──────── 同一临界区内 ────────┘
```

**代码体现**：

```cpp
// WaveManager.cpp 第68-74行 (markSorted)
{
    std::unique_lock<std::mutex> lock(m_lock);
    // ...
    complete = checkWaveCompleteLocked();
    if (complete)
    {
        // ★ exchange 在锁内执行，与 checkWaveCompleteLocked 原子化
        alreadyReported = m_bReported.exchange(true);
    }
}  // 锁在此释放

// 锁外判断：仅当 complete && !alreadyReported 时才发射信号
if (complete && !alreadyReported)
{
    emit waveReadyToReport(m_orderCode);
}
```

### 7.3 快速路径优化

在 `markSorted()` 和 `markException()` 中，当波次已回传时（`m_bReported == true`），走快速路径：

```cpp
// 快速路径：使用 relaxed 内存序读取，仅需原子性不需顺序保证
if (m_bReported.load(std::memory_order_relaxed))
{
    // 仅记录数据，不检查完成条件，不发射信号
    m_setCodeSorted.insert(code);
    // ...
    lock.unlock();
    emit codeMarked(code, true);
    return;
}
```

这避免了在波次已回传后仍然执行 `checkWaveCompleteLocked()` 的无效检查。

### 7.4 线程安全评估

| 场景 | 风险等级 | 保护措施 |
|------|---------|---------|
| 多线程同时 markSorted | ✅ 安全 | `m_lock` 互斥 |
| 多线程同时 markException | ✅ 安全 | `m_lock` 互斥 |
| markSorted + markException 并发 | ✅ 安全 | `m_lock` 互斥 |
| 重复回传 | ✅ 安全 | `m_bReported` 原子 + 锁内 exchange |
| 异步HTTP回调 | ✅ 安全 | Qt事件循环，单线程回调 |
| 状态查询并发 | ✅ 安全 | `m_lock` 保护数据读取 |

## 8. 接口规范

### 8.1 回传请求（WCS → WMS）

**请求方式**: `POST`  
**Content-Type**: `application/json; charset=UTF-8`  
**Header**: `AppKey: <app_key>`

**请求体格式**:

```json
{
  "head": {
    "orderCode": "PB202203200003",
    "orderType": "02",
    "sumLocation": "32",
    "operuserDate": "2026-07-23 14:01:59",
    "operuserCode": "admin",
    "operuserName": "管理员"
  }
}
```

**字段说明**:

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| `orderCode` | String | 波次号 | `m_orderCode` |
| `orderType` | String | 订单类型 | 固定 `"02"`（退货） |
| `sumLocation` | String | 格口总数 | `m_pBuffer->uniqueValueCount()` |
| `operuserDate` | String | 操作时间 | `QDateTime::currentDateTime()` |
| `operuserCode` | String | 操作人编码 | 固定 `"admin"` |
| `operuserName` | String | 操作人姓名 | 固定 `"管理员"` |

### 8.2 回传响应（WMS → WCS）

**预期响应**:

```json
{
  "success": true
}
```

**成功判定**: `response["success"] == true` 且 HTTP 状态码 200

### 8.3 超时配置

| 配置项 | 值 | 宏定义 | 位置 |
|--------|-----|--------|------|
| HTTP请求超时 | 2000ms | `HTTP_TIMEOUT_MS` | `define.h` 第23行 |
| 波次超时 | 0分钟（禁用） | `WAVE_TIMEOUT_MIN_DEFAULT` | `define.h` 第31行 |
