```
│  传输层    HTTP/1.1 over TCP                                    │
│  编码      JSON (UTF-8)                                         │
│  路由      POST /api/DispatchSortingCommand/InsertWaveInfo      │
│  端口      8191                                                 │
│  触发者    WMS 系统（自动）                                      │
│  响应      帧十一: 通用成功/错误帧                                │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 HTTP 请求帧

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                            HTTP 请求行                                        │
│  POST /api/DispatchSortingCommand/InsertWaveInfo HTTP/1.1                    │
│  Host: 127.0.0.1:8191                                                        │
│  Content-Type: application/json; charset=UTF-8                               │
│  Content-Length: <N>                                                         │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│                            JSON Body                                          │
│                                                                              │
│  {                                                                           │
│    "orderCode": "WAVE_20260724_001",     ← [必填] 波次单号，唯一标识          │
│    "orderQty":  "500",                   ← [必填] 订单总件数 (字符串)         │
│    "items": [                            ← [必填] SKU 列表                   │
│      {                                                                       │
│        "inco":       "WV34S1",           ← [必填] 国际单号/条码              │
│        "gridNum":    "122",              ← [必填] 目标格口号                 │

│        "gridType":   "normal",           ← [可选] 格口类型，默认 "普通格口"   │
│        "gridNumber": "1"                 ← [可选] 格口数量 (字符串→int)      │
│      },                                                                      │
│      {                                                                       │
│        "inco":       "WV34S2",                                                │
│        "gridNum":    "133",                                                   │
│        "gridType":   "priority",                                              │
│        "gridNumber": "1"                                                      │
│      }                                                                       │
│    ]                                                                         │
│  }                                                                           │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 成功响应帧

```json
{
  "resultCode": "0",
  "success":    true,
  "resultData": "accepted",
  "resultTime": "2026-07-24 15:30:45.0123"
}
```

### 2.4 特殊响应帧

**队列满（水位保护触发）：** HTTP 503

```json
{
  "resultCode": "503",
  "success":    false,
  "errorMsg":   "服务器繁忙",
  "resultTime": "2026-07-24 15:30:45.0123"
}
```

**Body 为空：** HTTP 400

```json
{
  "resultCode": "-1",
  "success":    false,
  "errorMsg":   "Body为空",
  "resultTime": "2026-07-24 15:30:45.0123"
}
```

### 2.5 帧处理流程

```
POST /api/DispatchSortingCommand/InsertWaveInfo
                │
                ▼
  ┌─────────────────────────────┐
  │ OnMessageComplete           │  HP-Socket HTTP 解析完成回调
  │ 提取 ConnState.body          │
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ 业务线程池 offload           │  异步化，HP-Socket Worker 立即返回
  │ commitNoWait(...)           │
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ processRequest()            │
  │ ├─ 队列满? → 返回503         │
  │ ├─ Body空? → 返回400         │
  │ └─ 正常: new WaveTask       │
  │    ├─ rawBody  = body       │  完整 JSON 拷贝到堆
  │    └─ recvTime = now_ms      │
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ TaskQueue::push(task)       │  生产者-消费者队列
  │ 水位保护: max = 5            │  超过则拒绝入队
  └─────────────┬───────────────┘
                │
                ▼
  ┌─────────────────────────────┐
  │ ParseWorker::run()          │  独立 QThread 消费
  │ ├─ JSON 解析 → orderCode    │
  │ ├─ 遍历 items[]             │
  │ │  ├─ 同品多格口合并         │  逗号拼接: "122,133,144"
  │ │  └─ 构建 QMap<inco,       │
  │ │            GridEntry>      │
  │ ├─ prepareSwap(newMap)      │  原子指针交换
  │ └─ emit waveParsed(...)     │  通知 WaveManager
  └─────────────────────────────┘
```

## 3. 帧二：格口查询帧

### 3.1 帧概览

```
┌─────────────────────────────────────────────────────────────────┐
│  帧名称    格口查询帧                                            │
│  帧编号    FRAME_02                                             │
│  方向      PLC/扫码枪 ──▶ WCS_httpServer                        │
│  传输层    HTTP/1.1 over TCP                                    │
│  编码      QueryString + JSON                                   │
│  路由      GET /api/query?code=<条码>                           │
│  端口      8191                                                 │
│  性能      DoubleBuffer 无锁读取 < 1μs                           │
│            全链路(含网络) < 5ms                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 HTTP 请求帧

```
GET /api/query?code=WV34S1 HTTP/1.1
Host: 127.0.0.1:8191
```

| 参数     | 类型          | 必填  | 说明          |
| ------ | ----------- | --- | ----------- |
| `code` | QueryString | 是   | 待查询的国际单号/条码 |

### 3.3 响应帧

**找到格口 — HTTP 200：**

```json
{
  "success":    true,
  "grid":       "122",
  "gridType":   "priority",
  "gridCount":  3,
  "orderCode":  "WAVE_20260724_001"
}
```

| 字段          | 类型     | 说明                                  |
| ----------- | ------ | ----------------------------------- |
| `success`   | bool   | 固定 true                             |
| `grid`      | string | 分配的格口号（多格口取第一个，逗号分隔取 first）         |
| `gridType`  | string | 格口类型："普通格口" / "priority" / "normal" |
| `gridCount` | int    | 该 SKU 映射的格口总数                       |
| `orderCode` | string | 所属波次单号                              |

**未找到格口 — HTTP 200（side effect: 自动标记异常）：**

```json
{
  "resultCode": "-1",
  "success":    false,
  "errorMsg":   "未找到格口映射",
  "resultTime": "2026-07-24 15:30:45.0123"
}
```

**缺少 code 参数 — HTTP 200：**

```json
{
  "resultCode": "-1",
  "success":    false,
  "errorMsg":   "缺少code参数",
  "resultTime": "2026-07-24 15:30:45.0123"
}
```

### 3.4 帧处理流程

```
GET /api/query?code=WV34S1
                │
                ▼
  ┌─────────────────────────────────────────────┐
  │ handleQuery("WV34S1")                       │
  │                                             │
  │  code 为空?  ──▶ 返回 "缺少code参数"         │
  │                                             │
  │  ↓                                          │
  │  e = WaveManager::getGrid(code)             │
  │      │                                      │
  │      └──▶ DoubleBuffer::get(key)            │
  │           ┌──────────────────────────┐      │
  │           │ m_pActive.load(acquire)   │ 原子 │
  │           │ pMap->constFind(key)     │ 无锁 │
  │           │ return GridEntry         │      │
  │           └──────────────────────────┘      │
  │                                             │
  │  gridNum 为空?                              │
  │  ├─ Yes: markException(code) + 返回"未找到"  │
  │  │                                        │
  │  └─ No:                                    │
  │     ├─ 含逗号? split(',').first()          │
  │     └─ 返回 {grid, gridType, gridCount}    │
  └─────────────────────────────────────────────┘
```

## 4. 帧三：分拣标记帧

### 4.1 帧概览

```
┌─────────────────────────────────────────────────────────────────┐
│  帧名称    分拣标记帧                                            │
│  帧编号    FRAME_03                                             │
│  方向      PLC/扫码枪 ──▶ WCS_httpServer                        │
│  传输层    HTTP/1.1 over TCP                                    │
│  编码      JSON                                                 │
│  路由      POST /api/markSorted                                 │
│  端口      8191                                                 │
│  副作用    触发波次完成判定 → 可能触发帧六回传                     │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 HTTP 请求帧

```
POST /api/markSorted HTTP/1.1
Host: 127.0.0.1:8191
Content-Type: application/json; charset=UTF-8
Content-Length: 20

{"code":"WV34S1"}
```

| 字段     | 类型     | 必填  | 说明       |
| ------ | ------ | --- | -------- |
| `code` | string | 是   | 已完成分拣的条码 |

### 4.3 响应帧

```json
{
  "success":       true,
  "waveComplete":  false,
  "orderCode":     "WAVE_20260724_001"
}
```

| 字段             | 类型     | 说明          |
| -------------- | ------ | ----------- |
| `success`      | bool   | 标记操作成功      |
| `waveComplete` | bool   | 当前波次是否已全部完成 |
| `orderCode`    | string | 当前波次单号      |

### 4.4 帧处理流程

```
POST /api/markSorted {"code":"WV34S1"}
                │
                ▼
  ┌────────────────────────────────────────────────┐
  │ WaveManager::markSorted("WV34S1")              │
  │                                                │
  │  lock(m_lock)                                  │
  │  │                                             │
  │  ├─ 快速路径: m_bReported == true ?             │
  │  │   仅记录状态 + 跳过判定 + 返回                 │
  │  │                                             │
  │  ├─ 正常路径:                                   │
  │  │   m_setCodeSorted.insert(code)               │
  │  │   m_setCodeProcessing.remove(code)           │
  │  │   m_mapCodeRetry.remove(code)                │
  │  │                                             │
  │  │   首个分拣? → emit waveSortingStarted         │
  │  │             → setState(WAVE_SORTING)         │
  │  │                                             │
  │  │   checkWaveCompleteLocked()                  │
  │  │   ┌───────────────────────────────────┐     │
  │  │   │ total = m_setCodeRecv.size()       │     │
  │  │   │ done  = sorted + exception         │     │
  │  │   │ done >= total ? → complete=true   │     │
  │  │   │ OR elapsed > timeout ? → true      │     │
  │  │   └───────────────────────────────────┘     │
  │  │                                             │
  │  │   complete == true ?                        │
  │  │   alreadyReported = m_bReported.exchange(true)│
  │  │                 ↑ 原子操作, 防止重复回传     │
  │  │                                             │
  │  unlock(m_lock)                                │
  │                                                │
  │  complete && !alreadyReported  ?               │
  │  ├─ emit waveReadyToReport(orderCode)          │
  │  └─ setState(WAVE_COMPLETING)                  │
  └────────────────────────────────────────────────┘
```

### 5.4 帧三 vs 帧四 处理差异

```
                    帧三 markSorted        帧四 markException
                    ──────────────         ─────────────────
插入集合:           m_setCodeSorted        m_setCodeException
重试计数:           清除 m_mapCodeRetry     递增 m_mapCodeRetry[code]
最大重试:           —                       max = WAVE_MAX_RETRY (3)
参与完成判定:       是                      是
触发回传:           可能                    可能
```

## 6. 帧五：波次状态查询帧

### 6.1 帧概览

```
┌─────────────────────────────────────────────────────────────────┐
│  帧名称    波次状态查询帧                                        │
│  帧编号    FRAME_05                                             │
│  方向      管理终端 ──▶ WCS_httpServer                           │
│  传输层    HTTP/1.1 over TCP                                    │
│  编码      JSON                                                 │
│  路由      GET /api/waveStatus                                  │
│  端口      8191                                                 │
│  用途      UI 展示 / 外部监控                                    │
└─────────────────────────────────────────────────────────────────┘
```

### 6.2 HTTP 请求帧

```
GET /api/waveStatus HTTP/1.1
Host: 127.0.0.1:8191
```

无参数。

### 6.3 响应帧 (WaveSnapshot)

```json
{
  "success":        true,
  "orderCode":      "WAVE_20260724_001",
  "waveStatus":     2,
  "statusText":     "分拣中",
  "orderQty":       500,
  "skuCount":       45,
  "sortedCount":    320,
  "exceptionCount": 2,
  "totalRecv":      500,
  "sumLocation":    18,
  "elapsedSec":     125
}
```

| 字段               | 类型     | 说明                                                                   |
| ---------------- | ------ | -------------------------------------------------------------------- |
| `success`        | bool   | 固定 true                                                              |
| `orderCode`      | string | 波次单号                                                                 |
| `waveStatus`     | int    | 状态码: 0=IDLE, 1=RECEIVED, 2=SORTING, 3=COMPLETING, 4=CLEANED, 5=ERROR |
| `statusText`     | string | 中文状态文本                                                               |
| `orderQty`       | int    | WMS 推送的总件数                                                           |

| `totalRecv`      | int    | 波次接收的条码总数（= sorted + exception + processing）                         |

### 6.4 sumLocation 计算逻辑

```
sumLocation = DoubleBuffer::uniqueValueCount()

计算过程:
  for each GridEntry in activeMap:
      if gridNum contains ',':
          split by ',' → count each unique grid
      else:
          count this grid

示例:
  SKU_A → grid "122,133"     → 2 个唯一格口
  SKU_B → grid "122"         → 与上面重复，不增加
  SKU_C → grid "144"         → 新增

  sumLocation = 3  (格口 122, 133, 144)
```

```
         │

  │                                      │
  │ 对每个匹配的帧:                        │

  │       批次开始 (仅日志)                │

  │                                      │
```

### 14.2 帧设计原则总结

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                           帧设计原则                                           │
│                                                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │  1. 分层清晰                                                         │    │
│  │     传输层: TCP (HP-Socket IOCP)                                     │    │
│  │     应用层: HTTP/1.1 + JSON / TCP 文本 / Snap7 二进制                 │    │
│  │                                                                      │    │
│  │  2. 错误统一                                                         │    │
│  │     所有 HTTP JSON 响应使用相同结构:                                   │    │
│  │     {resultCode, success, errorMsg/resultData, resultTime}          │    │
│  │                                                                      │    │
│  │  3. 超时保护                                                         │    │
│  │     WMS 回传: 2000ms (HTTP_TIMEOUT_MS)                               │    │
│  │     PLC 发送: 5000ms (PLC_SEND_TIMEOUT_MS)                           │    │
│  │     HTTP 请求: 3000~5000ms (curl --max-time)                        │    │
│  │                                                                      │    │
│  │  4. 异步化                                                           │    │
│  │     帧一: HP-Socket → 业务线程池 offload                             │    │
│  │     帧六: QNetworkAccessManager 异步 POST                            │    │
│  │     帧八: Snap7 同步写入 (PLC 协议本身是同步的)                       │    │
│  │                                                                      │    │
│  │  5. 防重复                                                           │    │
│  │     帧六: atomic<bool> m_bReported.exchange(true)                    │    │
│  │     仅第一个判定线程触发回传，后续线程跳过                              │    │
│  │                                                                      │    │
│  │  6. 水位保护                                                         │    │
│  │     帧一: TaskQueue 最大排队 5 个 (TASK_QUEUE_MAX_SIZE)              │    │
│  │     超过返回 503 "服务器繁忙"                                         │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 15.2 帧状态码速查

```
波次状态 (帧五 waveStatus 字段):
  0  IDLE        空闲，可接收新波次
  1  RECEIVED    已接收 WMS 推送，等待分拣
  2  SORTING     分拣进行中
  3  COMPLETING  回传中（已触发帧六）
  4  CLEANED     已完成清理
  5  ERROR       异常状态

HTTP 状态码:
  200  成功
  400  Body 为空
  404  未知 API 路径
  503  任务队列满

错误码 (帧十一 resultCode):
  "0"   成功
  "-1"  通用错误
  "404" 路径不存在
  "503" 队列满
```
