# WMS 退货分拣 HTTP 服务 — 系统配置说明报告

> 版本：1.0.0 | 日期：2026-07-24 | 面向：现场部署/运维人员

---

## 一、配置体系总览

系统采用 **三层配置架构**，从编译期到运行期逐级覆盖：

| 层级 | 配置方式 | 生效方式 | 适用场景 |
|------|----------|----------|----------|
| **编译期** | `define.h` 宏定义 | 重新编译 | 系统级参数（端口、线程数、超时） |
| **运行期-文件** | `config/http_server.xml` | 启动加载 + 保存即时生效 | 业务参数（URL、AppKey、环境切换） |
| **运行期-UI** | 主窗口"配置"面板 | 保存即时生效（端口需重启） | 现场人员调整 |

```
┌─ 编译期 (define.h) ─────────────────────────────────┐
│  端口、IP、线程数、超时、保活间隔等底层参数            │
│  → 重新编译后生效                                     │
└──────────────────────────────────────────────────────┘
                    ↓ 作为默认值写入
┌─ 运行期 (http_server.xml) ───────────────────────────┐
│  首次运行自动生成，后续可 UI 修改                       │
│  URL、AppKey、超时、环境切换                           │
└──────────────────────────────────────────────────────┘
                    ↓ 加载 & 保存
┌─ UI 面板 (MainWindow) ───────────────────────────────┐
│  端口、回传URL、AppKey、测试环境、超时、日志保留天数   │
│  → 保存后即时生效（端口需重启）                        │
└──────────────────────────────────────────────────────┘
```

## 二、编译期配置（define.h）

所有系统级参数集中在 `WCS_httpServer/WCS_httpServer/define.h` 中，修改后需重新编译。

### 2.1 服务端口

| 宏名称 | 默认值 | 说明 |
|--------|--------|------|
| `WMS_LISTEN_PORT` | 8191 | WMS 波次推送 + 查询 API 监听端口 |
| `PLC_LISTEN_PORT` | 8192 | PLC TCP 反馈监听端口 |

### 2.2 WMS 回传接口

| 宏名称 | 默认值 | 说明 |
|--------|--------|------|
| `WMS_FEEDBACK_URL` | `http://47.93.21.77:9090/.../dz_bxh_wcs_zs` | 正式环境回传地址 |
| `WMS_FEEDBACK_URL_TEST` | `http://182.92.166.232/.../dz_bxh_wcs_cs` | 测试环境回传地址 |
| `WMS_APPKEY` | `dz_bxh_wcs_zs` | 正式环境 AppKey |
| `WMS_APPKEY_TEST` | `dz_bxh_wcs_cs` | 测试环境 AppKey |

### 2.3 PLC 通信（S7 + TCP）

| 宏名称 | 默认值 | 说明 |
|--------|--------|------|
| `PLC_S7_IP` | `192.168.0.1` | PLC S7 连接 IP（**需按实际修改**） |
| `PLC_S7_RACK` | 0 | S7 机架号 |
| `PLC_S7_SLOT` | 1 | S7 槽位号 |
| `PLC_S7_DB_NUM` | 1 | 分拣数据 DB 块编号 |
| `PLC_S7_WRITE_OFFSET` | 1000 | 条码写入地址偏移 |
| `PLC_S7_WRITE_SIZE` | 42 | 条码写入数据大小（字节） |
| `PLC_SEND_TIMEOUT_MS` | 5000 | S7 发送超时(ms) |
| `PLC_RECONNECT_INTERVAL_MS` | 3000 | 断线重连间隔(ms) |

### 2.4 性能与线程

| 宏名称 | 默认值 | 说明 |
|--------|--------|------|
| `HP_WORKER_THREADS` | 16 | I/O 工作线程数 |
| `HP_MAX_CONNECTIONS` | 500 | 最大连接数 |
| `HP_KEEPALIVE_TIME_MS` | 10000 | KeepAlive 探活间隔(ms) |
| `BUSINESS_POOL_SIZE` | 90 | 业务线程池大小 |
| `TASK_QUEUE_MAX_SIZE` | 5 | 任务队列最大排队数 |

### 2.5 超时与重试

| 宏名称 | 默认值 | 说明 |
|--------|--------|------|
| `HTTP_TIMEOUT_MS` | 3000 | HTTP 回传超时(ms) |
| `WAVE_COMPLETE_TIMEOUT_MS` | 2000 | 波次完成回传超时(ms) |
| `WAVE_MAX_RETRY` | 3 | 异常 SKU 最大重试次数 |
| `WAVE_TIMEOUT_MIN_DEFAULT` | 0 | 波次超时默认值(分钟，0=不超时) |

## 三、运行期配置（http_server.xml）

### 3.1 配置文件位置

```
{exe目录}/config/http_server.xml
```

### 3.2 首次运行自动生成

程序启动时自动检测 `config/http_server.xml` 是否存在：

- **不存在** → 使用 `define.h` 中的宏值作为默认值，自动创建配置文件
- **已存在** → 加载现有配置

### 3.3 配置文件内容

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <wmsListenPort>8191</wmsListenPort>            <!-- 监听端口 -->
    <feedbackUrl>http://47.93.21.77:9090/...</feedbackUrl>
    <feedbackTestUrl>http://182.92.166.232/...</feedbackTestUrl>
    <appkey>dz_bxh_wcs_zs</appkey>
    <appkeyTest>dz_bxh_wcs_cs</appkeyTest>
    <useTestEnv>1</useTestEnv>                      <!-- 1=测试环境, 0=正式环境 -->
    <waveTimeoutMin>0</waveTimeoutMin>               <!-- 波次超时(分钟) -->
    <maxRetryCount>3</maxRetryCount>                 <!-- 最大重试次数 -->
    <logRetainDays>30</logRetainDays>                <!-- 日志保留天数 -->
</config>
```

### 3.4 配置项实时生效说明

| 配置项 | 保存后即时生效 | 说明 |
|--------|:-------------:|------|
| 回传URL | 是 | 下次回传即用新地址 |
| AppKey | 是 | 下次回传即用新 Key |
| 测试环境开关 | 是 | 切换后 URL 和 AppKey 同时切换 |
| 波次超时 | 是 | 当前波次即生效 |
| 监听端口 | **否** | 必须重启服务，UI 会显示红色 `(需重启)` 提示 |
| 最大重试次数 | 是 | 下次异常重试即生效 |
| 日志保留天数 | 是 | 下次日志清理即生效 |

## 四、UI 配置面板操作指南

### 4.1 面板布局

```
┌─ 配置 ───────────────────────────────────────────────┐
│                                                       │
│  监听端口: [8191]  ↑↓                                  │
│  回传地址: [http://...]  ← 正式/测试环境自动切换       │
│  AppKey:   [dz_bxh_wcs_zs]                             │
│  ☑ 使用测试环境  ← 勾选后 URL/AppKey 自动切换为测试值   │
│  波次超时: [0] 分钟 (0=不超时)                          │
│  日志保留: [30] 天                                      │
│                                                       │
│  [保存配置]  ← 点击后即时生效，日志区显示结果            │
│                                                       │
└───────────────────────────────────────────────────────┘
```

### 4.2 操作步骤

1. **修改参数**：直接在对应输入框中修改
2. **环境切换**：勾选/取消"使用测试环境"，URL 和 AppKey 自动切换
3. **保存**：点击"保存配置"按钮
4. **验证**：查看日志区输出"配置已保存并生效"即表示成功

### 4.3 端口变更特别说明

端口变更后日志区会显示：
```
端口已变更 8191→8192，需重启服务生效
```

端口标签同步变为红色 `端口: 8192 (需重启)`，提醒现场人员操作。

## 五、日志配置

### 5.1 配置文件

```
{exe目录}/log4cxx.properties
```

### 5.2 日志模块与存储路径

| 模块 | 文件路径 | 内容 |
|------|----------|------|
| WCS | `./log/WCS/WCS.log` | 波次管理、分拣状态 |
| HTTP | `./log/HTTP/http.log` | 请求分发、WMS回传 |
| PLC | `./log/PLC/PLC.log` | PLC 连接、收发、心跳 |
| LIFECYCLE | `./log/LIFECYCLE/lifecycle.log` | 条码全生命周期追踪 |
| Run | `./log/Run/run.log` | 程序运行日志 |
| DataBase | `./log/DataBase/data.log` | 数据库操作 |
| Image | `./log/Image/data.log` | 图片处理 |
| JT | `./log/JT/JT.log` | 极兔分拣 |
| PLCWarn | `./log/PLCWarn/PLCWarn.log` | PLC 告警 |

### 5.3 滚动策略

- 单文件最大 100MB
- 最多保留 80 个历史文件（约 8GB）
- 日志保留天数可通过 UI 配置（默认 30 天）

## 六、部署时客户需配置项

以下为现场部署时**必须修改**的配置项：

| 序号 | 配置项 | 配置位置 | 默认值 | 说明 |
|:----:|--------|----------|--------|------|
| 1 | PLC IP 地址 | `define.h` → `PLC_S7_IP` | `192.168.0.1` | 修改为实际 PLC 的 IP 地址 |
| 2 | WMS 回传 URL | UI 配置面板 | 预设正式/测试地址 | 对接客户 WMS 系统 |
| 3 | WMS AppKey | UI 配置面板 | 预设值 | 对接客户 WMS 认证 |
| 4 | 监听端口 | UI 配置面板 | 8191 | 如与现有服务冲突需修改 |
| 5 | 波次超时 | UI 配置面板 | 0(不超时) | 根据业务需求设定 |
| 6 | 环境切换 | UI 配置面板 | 测试环境 | 上线前切换为正式环境 |

### 部署检查清单

- [ ] `define.h` 中 `PLC_S7_IP` 已修改为实际 PLC IP
- [ ] 重新编译程序
- [ ] 启动服务，确认 S7 状态显示绿色"已连接"
- [ ] 在 UI 中配置正确的 WMS 回传 URL 和 AppKey
- [ ] 取消勾选"使用测试环境"，切换为正式环境
- [ ] 点击"保存配置"，确认日志显示"配置已保存并生效"
- [ ] 检查 `./log/` 目录下各模块日志文件正常生成
