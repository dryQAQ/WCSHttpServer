API 路由总览

序号路由方向触发时机数据库操作
①POST /api/.../BindingLatticePort仓库管理系统 → WCS仓库管理系统 扫码绑定写入容器绑定表
②POST /api/.../InsertWaveInfo仓库管理系统 → WCS仓库管理系统 创建波次写入波次头表 + 波次明细表
③POST /api/rfid/carNumReportRFID → WCSRFID 扫描到 EPC+小车号无（仅内存缓存）
④TCP + S7 协议PLC → WCSPLC 落格/锁格写入分拣记录表 + 异常记录表
3字段: {EPC|格口|小车}
5字段: {EPC|格口|首车|尾车|状态}
⑤POST gwisSubProductClassifyOrderWCS → 仓库管理系统格口满箱写入满箱回传表 + 更新容器绑定表
⑥POST gwisSubProductClassifyEndOrderWCS → 仓库管理系统用户点击结束任务按钮写入完结回传表 + 更新波次头表
取消POST /api/.../InsertWaveIn仓库管理系统 → WCS仓库管理系统 取消波次更新波次头表 状态=已取消

数据库表结构

表名用途写入时机持久化
return_wave（波次头表）波次基本信息H4 下发 / H5 取消 / H8 完结跨任务保留
return_wave_item（波次明细表）SKU→格口 分配明细H4 下发新波次覆盖更新
grid_box_bind（容器绑定表）格口→容器 绑定关系H6 绑定 / H7 满箱归档历史完整保留
sorting_records（分拣记录表）每条落格分拣记录PLC 落格反馈跨任务累积
exception_record（异常记录表）异常事件记录分拣异常时跨任务累积
outbox_fullbox（满箱回传表）H7 满箱回传消息队列格口锁格跨任务保留
outbox_end（完结回传表）H8 完结回传消息队列波次完结跨任务保留
