## 三、完整触发链路

```mermaid
sequenceDiagram
    participant PLC as PLC 分拣机
    participant PM as PlcManager
    participant HP as HttpServer
    participant WM as WaveManager
    participant SD as SortingDatabase
    participant MW as MainWindow
    participant HC as HttpClient
    participant WMS as WMS

    rect rgb(240, 248, 255)
        Note over PLC,HP: ██ 触发: PLC 锁格信号
        Note over PLC: 格口满箱 → PLC 发送锁格信号
        PLC->>PM: S7 DB77 锁格状态变化
        PM->>PM: 解析锁格信号
        PM->>HP: emit gridLocked(grid="001")
        Note over HP: QueuedConnection 主线程处理
    end

    rect rgb(255, 248, 240)
        Note over HP,SD: ██ 阶段1: 快照 + 锁格回传
        HP->>HP: 快照上下文<br>orderCode, waveStatus, sorted, exc, boxCode, gridRecords
        HP->>HP: sendGridLockFeedback(grid)<br>步骤1: 锁格回传分拣明细
    end

    rect rgb(240, 255, 240)
        Note over HP,SD: ██ 阶段2: 满箱回传报文构建
        HP->>HP: sendFullbox(grid)
        HP->>WM: triggerFullbox() → SORTING→FULLBOX_SYNC
        HP->>HP: 获取容器绑定 boxCode
        HP->>HP: 获取该格口分拣记录 records[]
        HP->>HP: buildFullboxPayload(orderCode, grid, boxCode, records)
        Note over HP: 组装 head + detailList JSON
        HP->>SD: insertOutboxFullbox(outMsg)
        Note over SD: 插入 outbox_fullbox 表<br>status=pending, retryCount=0
    end

    rect rgb(255, 240, 255)
        Note over MW,WMS: ██ 阶段3: 可靠投递 → WMS
        HP->>MW: emit fullboxReportReady(payload, msgId)
        MW->>HC: sendGenericFeedback(payload, "fullbox_" + msgId)
        HC->>WMS: HTTP POST<br>method=gwisSubProductClassifyOrder

        alt WMS 返回成功
            WMS-->>HC: {"success":true}
            HC-->>MW: reportResult(msgId, true, body)
            MW->>HP: onFullboxReplyFinished(msgId, true, body)
            HP->>SD: markOutboxFullboxSuccess(msgId)
            HP->>HP: 归档容器绑定
            HP->>WM: 状态回 SORTING
        else WMS 返回失败
            WMS-->>HC: {"success":false}
            HC-->>MW: reportResult(msgId, false, body)
            MW->>HP: onFullboxReplyFinished(msgId, false, body)
            HP->>SD: 更新 Outbox 重试信息
            Note over SD: retryCount++, nextRetry 更新
        end
    end

    rect rgb(240, 240, 255)
        Note over SD,WMS: ██ 阶段4: Outbox 重试（失败时）
        loop 定时扫描（OUTBOX_RETRY_INTERVAL_SEC）
            HP->>SD: pollOutboxFullbox()<br>查询 pending/retrying 消息
            alt 有待重试消息
                SD-->>HP: 返回 pending 消息列表
                HP->>MW: emit fullboxReportReady(payload, msgId)
                Note over MW: 重试发送
            end
        end
    end
```

## 五、Outbox 可靠投递机制

```mermaid
flowchart TD
    subgraph 写入["满箱触发"]
        A["sendFullbox(grid)"] --> B["buildFullboxPayload()"]
        B --> C["生成 msgId (UUID)"]
        C --> D["insertOutboxFullbox()"]
        D --> E["outbox_fullbox 表<br>status=pending, retry_count=0"]
    end

    subgraph 首次发送["首次发送"]
        E --> F["sendFullboxToWms(msgId, payload)"]
        F --> G["emit fullboxReportReady"]
        G --> H["MainWindow → HttpClient"]
        H --> I["HTTP POST to WMS"]
    end

    subgraph 结果处理["结果处理"]
        I --> J{"WMS 响应?"}
        J -->|"成功"| K["markOutboxFullboxSuccess(msgId)"]
        K --> L["归档容器绑定"]
        L --> M["状态回 SORTING"]
        J -->|"失败"| N["updateOutboxFullboxRetry()"]
        N --> O["retry_count++, next_retry 更新"]
    end

    subgraph 重试["重试调度"]
        O --> P["pollOutboxFullbox() 定时器"]
        P --> Q{"status=pending/retrying<br>AND next_retry <= now?"}
        Q -->|"是"| R["取出消息"]
        R --> S{"retry_count < OUTBOX_MAX_RETRIES?"}
        S -->|"是"| F
        S -->|"否"| T["标记 status=failed<br>重试耗尽"]
        Q -->|"否"| P
    end

    E --> P
```

### 相关配置宏（define.h）

| 宏 | 默认值 | 说明 |
|----|--------|------|
| `OUTBOX_RETRY_INTERVAL_SEC` | 30 | 重试间隔（秒） |
| `OUTBOX_MAX_RETRIES` | 5 | 最大重试次数 |
| `WMS_METHOD_FULLBOX` | `"gwisSubProductClassifyOrder"` | 满箱回传 method |
| `FULLBOX_FROM_LOCATION_SOURCE` | `"volu"` | fromLocation 来源 |
| `FULLBOX_DEFAULT_FROM_LOCATION` | `"A-01-01"` | 默认来源库位 |

## 八、与 InsertWaveInfo 的对比

| 对比项 | InsertWaveInfo（H4） | 满箱回传（H7） |
|--------|---------------------|---------------|
| 方向 | WMS → WCS | WCS → WMS |
| 触发时机 | WMS 主动下发波次 | PLC 锁格信号自动触发 |
| 报文位置 | 根节点直接 items[] | head.detailList[] |
| 字段用途 | 波次计划（格口分配） | 满箱汇总（实分结果） |
| 可靠性 | 无（WMS 可重试下发） | Outbox 可靠投递 + 重试 |
