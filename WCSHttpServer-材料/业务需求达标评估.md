## 通用设计

### 响应格式统一

所有 HTTP API 接口均采用统一的响应格式，`code` 字段约定为 `"200"` 表示成功、`"500"` 表示服务器内部错误，`message` 字段统一附加可读的说明信息，便于 WMS 侧统一解析与异常处理。

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | `"200"` 成功，`"500"` 失败 |
| `message` | string | 可读的描述信息（成功或错误原因） |
| `data` | object（可选） | 业务数据载荷，接口有返回值时携带 |

### 波次明细日志 WAVE_ITEM 模块

系统新增 `WAVE_ITEM` 日志模块，专门用于记录波次明细的完整生命周期。每条波次明细（wave_item）从创建、分拣落格、到完成回传的关键节点均会输出结构化日志，便于运维排查和数据追溯。

| 日志节点 | 说明 |
|----------|------|
| 波次明细入库 | 记录每个 item 的 barcode、epcn、gridNum 等核心字段 |
| 分拣落格 | 记录 PLC 反馈的落格结果，关联 barcode 与格口号 |
| 满箱触发 | 记录满箱判断依据（当前数量 / 上限） |
| 回传 WMS | 记录满箱或波次完成时的回传报文内容 |
