# 1、收货任务下发

## 1.1 概述

该接口用于wms向wcs下发收货线任务数据

- 服务端：wcs
- 客户端：wms

## 1.2 接口详情

| 项目   | 内容    |
| ---- | ----- |
| 请求方式 | POST  |
| 编码格式 | utf-8 |
| 参数类型 | json  |

### 请求参数

| 参数名           | 类型     | 是否必填 | 备注     |
| ------------- | ------ | ---- | ------ |
| orderCode     | String | 是    | 订单号    |
| sentTime      | String | 是    | 接口发送时间 |
| items.boxCode | String | 是    | 容器码    |
| items.dest    | String | 是    | 分拣格口   |

### 响应参数

| 参数名      | 类型     | 是否必填 | 备注                                |
| -------- | ------ | ---- | --------------------------------- |
| code     | String | 是    | 响应码（成功 `"200"`，失败 `"500"`）         |
| message  | String | 否    | 异常原因，异常时输出                        |
| sentTime | String | 是    | 响应时间，格式（2021-06-24 19:15:51.480） |

### 请求示例

```json
{
  "orderCode": "orderCode1",
  "sentTime": "2020-12-21 05:53:57.000",
  "items": [
    {
      "boxCode": "b0000000001",
      "dest": "101"
    },
    {
      "boxCode": "b0000000002",
      "dest": "102"
    }
  ]
}
```

### 成功响应示例

```json
{
  "code": "200",
  "message": "",
  "sentTime": "2020-12-21 05:53:57.000"
}
```

### 失败响应示例

```json
{
  "code": "500",
  "message": "订单号已存在，不允许重复下发",
  "sentTime": "2020-12-21 05:53:57.000"
}
```

# 2、退货任务格口分配

## 2.1 概述

该接口用于wms向wcs分配对应波次退货格口

- 服务端：wcs
- 客户端：wms

## 2.2 接口详情

| 项目   | 内容                                                                  |
| ---- | ------------------------------------------------------------------- |
| 请求地址 | `http://{WCS_IP}:8191/api/DispatchSortingCommand/InsertWaveInfo`    |
| 请求方式 | POST                                                                |
| 编码格式 | utf-8                                                               |
| 参数类型 | json                                                                |

### 请求参数

| 参数名              | 类型     | 是否必填 | 备注         |
| ---------------- | ------ | ---- | ---------- |
| orderCode        | String | 是    | 波次号        |
| orderQty         | Int    | 是    | 波次件数       |
| items            | List   | 是    | 明细数组       |
| items.obxCode    | String | 是    | 容器编码       |
| items.inco       | String | 是    | EPC编码（商品编码），WMS侧称为商品编码，即EPC标签值 |
| items.gridNum    | String | 是    | 格口号        |
| items.gridNumber | String | 是    | 格口总件数      |
| items.gridType   | String | 是    | 格口属性       |
| items.epcn       | String | 否    | EPC标签值（可选） |

### 响应参数

| 参数名      | 类型     | 是否必填 | 备注                                |
| -------- | ------ | ---- | --------------------------------- |
| code     | String | 是    | 响应码（成功 `"200"`，失败 `"500"`）         |
| message  | String | 否    | 异常原因，异常时输出                        |
| sentTime | String | 是    | 响应时间，格式（2026-08-10 12:00:00.000） |

### 请求示例

```json
{
  "orderCode": "PB202203200003",
  "orderQty": "12312",
  "items": [
    {
      "obxCode": "BOX202203200080",
      "inco": "WV34S1CN2001B60L",
      "gridNum": "1",
      "gridNumber": "100",
      "gridType": "普通格口",
      "epcn": "EPC202203200001"
    },
    {
      "obxCode": "BOX202203200081",
      "inco": "WV34S1CN2001B61L",
      "gridNum": "2",
      "gridNumber": "100",
      "gridType": "普通格口",
      "epcn": "EPC202203200002"
    }
  ]
}
```

### 成功响应示例

```json
{
  "code": "200",
  "message": "",
  "sentTime": "2026-08-10 12:00:00.000"
}
```

### 失败响应示例

```json
{
  "code": "500",
  "message": "格口绑定不完整(1/66)，请先完成全部容器绑定后再下发波次"
}
```

```json
{
  "code": "500",
  "message": "JSON解析失败: illegal value (offset=1)"
}
```

# 3、格口容器绑定

## 3.1 概述

该接口用于wms向wcs下发容器与格口的绑定关系

- 服务端：wcs
- 客户端：wms

## 3.2 接口详情

| 项目    | 内容                                                                                    |
| ----- | ------------------------------------------------------------------------------------- |
| 请求地址  | `http://{WCS_IP}:8191/api/DispatchSortingCommand/BindingLatticePort?latticehole=001&boxcode=BOX001` |
| 请求方式  | POST                                                                                  |
| 编码格式  | utf-8                                                                                 |
| 参数类型  | URL 查询参数                                                                              |
| URL传参 | `latticehole`=格口号&`boxcode`=容器号                                                         |

### 请求参数（URL查询参数）

| 参数名         | 类型     | 是否必填 | 备注  |
| ----------- | ------ | ---- | --- |
| latticehole | String | 是    | 格口号 |
| boxcode     | String | 是    | 容器号 |

### 响应参数

| 参数名     | 类型     | 是否必填 | 备注                           |
| ------- | ------ | ---- | ---------------------------- |
| code    | String | 是    | 响应码（成功 `"200"`，失败 `"500"`）    |
| message | String | 是    | 返回信息（成功时返回 `"收到信息"`）        |

### URL调用示例

```
http://{WCS_IP}:8191/api/DispatchSortingCommand/BindingLatticePort?latticehole=001&boxcode=BOX001
```

### 成功响应示例

```json
{
  "code": "200",
  "message": "收到信息"
}
```

### 失败响应示例

```json
{
  "code": "500",
  "message": "参数缺失: latticehole和boxcode均为必填"
}
```

# 4、退货任务取消

## 4.1 概述

该接口用于wms向wcs发退货任务取消指令

- 服务端：wcs
- 客户端：wms

## 4.2 接口详情

| 项目   | 内容                                                                |
| ---- | ----------------------------------------------------------------- |
| 请求地址 | `http://{WCS_IP}:8191/api/DispatchSortingCommand/InsertWaveIn`    |
| 请求方式 | POST                                                              |
| 编码格式 | utf-8                                                             |
| 参数类型 | json                                                              |

### 请求参数

| 参数名          | 类型     | 是否必填 | 备注   |
| ------------ | ------ | ---- | ---- |
| orderCode    | String | 是    | 波次号  |
| cancelReason | String | 否    | 取消原因 |

### 响应参数

| 参数名         | 类型      | 是否必填 | 备注                                |
| ----------- | ------- | ---- | --------------------------------- |
| code        | String  | 是    | 响应码（成功 `"200"`，失败 `"500"`）         |
| message     | String  | 否    | 异常原因，异常时输出                        |
| cancellable | Boolean | 是    | 是否可取消（`true` 可取消，`false` 不可取消）    |

### 请求示例

```json
{
  "orderCode": "PB202203200003",
  "cancelReason": "手动取消"
}
```

### 成功响应示例

```json
{
  "code": "200",
  "message": "取消成功",
  "cancellable": true
}
```

### 失败响应示例

```json
{
  "code": "500",
  "message": "波次已开始分拣，不允许取消",
  "cancellable": false
}
```

# 5、异常码汇总

所有接口异常统一使用 `"500"` 作为错误码，具体异常通过 `message` 字段描述。

| 异常码    | 说明                                   | 涉及接口        |
| ------ | ------------------------------------ | ----------- |
| `"500"` | 订单号已存在，不允许重复下发                       | 收货任务下发      |
| `"500"` | 格口绑定不完整，请先完成全部容器绑定后再下发波次              | 退货任务格口分配    |
| `"500"` | JSON解析失败                              | 退货任务格口分配    |
| `"500"` | 参数缺失: latticehole和boxcode均为必填        | 格口容器绑定      |
| `"500"` | 波次已开始分拣，不允许取消                        | 退货任务取消      |
| `"500"` | 波次不存在或已完结                            | 退货任务取消      |
| `"500"` | 其他业务异常                               | 所有接口        |

---

# 6、注意事项

1. 所有 HTTP 请求的 `Content-Type` 必须设置为 `application/json;charset=utf-8`。
2. 响应码 `code` 为字符串类型，成功返回 `"200"`，失败返回 `"500"`。
3. 所有接口的响应消息字段统一使用 `message`（小写），不再使用 `Message`、`msg` 等变体。
4. 请求体 JSON 需确保格式正确，避免尾部多余逗号、非法字符等问题。
5. 退货任务取消接口返回 `cancellable` 字段，调用方需根据该字段判断波次是否允许取消。
