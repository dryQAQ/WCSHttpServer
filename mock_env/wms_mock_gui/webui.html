?使用说明

      
一、这是什么

      

        鞋服窄带分拣项目中「WCS ↔ WMS」接口的联调测试台，与仓库现有仿真台（mock_env/mock_app.py）互补：
        仿真台负责全链路（RFID/PLC/S7/波次编排）；本测试台专注 WMS 接口，可直接拷到客户机使用。
        
· 你输入 SKU码 + 格口号（等业务参数）→ 自动生成与生产一致的报文（H7/H8/H4/H6）→ 可修改 → 发送到可配置地址；
        
· 内置 模拟WMS网关：报文正确 → 应答成功样例；报文错误 → 应答 success=false + 具体原因（按可配置规则判定）；
        
· 也可把地址指向 WMS测试/正式环境网关 或 真实WCS服务，看它们的真实响应。
      

      
二、启动

      

        双击 run.bat（或 python wms_mock_gui.py），自动打开本页。
        可选参数：--gui-port 9000 --gw-port 8099 --no-browser --no-gateway。
        整个目录可复制到任意机器（纯 Python 标准库，无第三方依赖）。
      

      
三、四种报文与判定口径

      

        
类型方向接口/method要点成功判定

        
H7 满箱回传WCS→WMS…/gwisSubProductClassifyOrder
method=gwisSubProductClassifyOrder		
            head{orderCode,orderType,warehouseCode,goodsOwner,fromLocation,createDate,…}+detailList[{num:格口编码,targetLocation:容器号,sku,qty}]
            响应JSON顶层 success==true

        
H8 完结回传WCS→WMS…/productClasTask/gwisSubProductClassifyEndOrder
            head{orderCode,orderType,sumLocation,operuserDate,operuserCode,operuserName}
            响应JSON顶层 success==true

        
H4 波次下发WMS→WCS/api/DispatchSortingCommand/InsertWaveInfo
            {orderCode,orderQty(须=ΣgridNumber),items:[{inco=SKU,gridNum,gridNumber,gridType}]}；未点「开始接收任务」WCS返回HTTP500
            HTTP200 且 code=="200"

        
H6 容器绑定WMS→WCS/api/DispatchSortingCommand/BindingLatticePort
?latticehole=格口&boxcode=容器		
            查询参数报文，无JSON体；满箱禁用后重绑即恢复格口
            HTTP200 且 code=="200"

      

      
四、把真实 WCS 的 H7/H8 接入本模拟网关

      

        ① 在「③规则与主数据」确认期望AppKey（默认测试环境 dz_bxh_dmwcs_cs，与 WCS 配置 appkeyTest 同值，勿与正式 dz_bxh_wcs_zs 混用）；
        
② 本机联调：直接运行仓库 mock_env/启用Mock配置.bat 后，WCS 回传 URL 已指向 127.0.0.1:8099（本测试台默认端口）；
        
③ WCS 在其它机器：手工改 WCS 的 config/http_server.xml 中 feedbackTestUrl / feedbackEndTestUrl 主机为本机IP，
        并保证本测试台网关监听 0.0.0.0（默认）；改完重启 WCS；
        
④ 之后在 WCS 上锁格/结束任务 → 这里实时出现 H7/H8 与校验判定；「强制失败」可演练 WCS Outbox 自动重试。
      

      
五、常见问题

      

        · 8099 被占用：仿真台 mock_app.py 也在监听 8099，两者不要同时开；或在本页改端口（真实 WCS 接入时需同步改回传URL）。
        
· H7 应答失败后 WCS 何时重发：H7 出站约 30s×2 重试、H8 约 5s×3 —— 与生产一致，可开「强制失败」观察。
        
· 想连 WMS 测试/正式环境：报文类型 H7/H8，预设选「wmstest.pelliot.com.cn:9090」或正式网关并核对 AppKey；响应为真实网关判定。
        
· 报文是修改后的：点「发送」发送的就是当前文本框内容；「格式化」仅排版不改变内容。
        
· 本工具不连数据库：全部状态自动保存在同目录 wms_mock_state.json，删除该文件即恢复出厂默认。
