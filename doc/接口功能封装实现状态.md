## 二、已实现功能详细说明

### 2.1 退货格口分配（InsertWaveInfo）

**接口路径**: `POST /api/DispatchSortingCommand/InsertWaveInfo`

**宏定义**: [define.h#L100](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/define.h#L100)

**功能说明**:

- WMS 推送波次数据，包含条码与格口的映射关系
- WCS 将原始 JSON 报文入队，由 ParseWorker 后台解析
- 解析结果写入 `DoubleBuffer`（条码 → GridEntry 映射）
- 解析完成后通知 `WaveManager` 注册波次，状态变为 `RECEIVED`

**代码位置**:

- 路由入口: [HttpServer.cpp:331-356](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpServer.cpp#L331-L356)
- 解析与数据写入: [ParseWorker](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/ParseWorker.h) / [DoubleBuffer.h](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/DoubleBuffer.h)
- 状态机注册: [WaveManager::setWaveData](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/WaveManager.cpp#L10-L28)

**响应格式**:

```json
{
  "code": "200",
  "message": "accepted",
  "sentTime": "2026-07-27 10:00:00.000"
}
```

### 2.3 回传反馈（WCS → WMS）

**接口性质**: WCS 主动发起的 HTTP POST，非 WMS 调用 WCS 的接口

**目标路径**: 由 `WMS_FEEDBACK_PATH` / `WMS_FEEDBACK_PATH_TEST` 定义，见 [define.h:19-20](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/define.h#L19-L20)

**触发时机**:

1. **自动回传**: 当 `WaveManager` 判定波次完成时，发射 `waveReadyToReport` 信号，[MainWindow.cpp:405-410](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/MainWindow.cpp#L405-L410) 中调用 `HttpClient::sendWaveComplete`
2. **手动回传**: UI 点击"手动回传"按钮触发，见 [MainWindow.cpp:719-733](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/MainWindow.cpp#L719-L733)

**功能说明**:

- 构造回传 JSON，包含 `orderCode`、`orderType`、`sumLocation`、`operuserDate` 等字段
- 通过 `QNetworkAccessManager` 异步 POST 到 WMS 回传 URL
- 设置超时定时器（默认 3000ms）
- 回传成功 → 波次状态变为 `CLEANED`；失败 → 状态变为 `ERROR`，可手动重试

**代码位置**:

- 发送实现: [HttpClient.cpp:33-86](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpClient.cpp#L33-L86)
- 类定义: [HttpClient.h](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpClient.h)
- 触发连接: [MainWindow.cpp:405-428](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/MainWindow.cpp#L405-L428)

**回传报文示例**:

```json
{
  "head": {
    "orderCode": "PB202507270001",
    "orderType": "02",
    "sumLocation": "15",
    "operuserDate": "2026-07-27 10:30:00",
    "operuserCode": "WCS01",
    "operuserName": "WCS系统"
```

## 三、退货任务取消（InsertWaveIn）详细说明

### 3.1 接口文档来源

**依据**: 德马-奔赴自然接口文档 v1.0 §4 退货任务取消，明确使用 `POST /api/DispatchSortingCommand/InsertWaveIn` 作为取消接口。

### 3.2 接口规格（与 WMS 文档一致）

**请求示例**:

```json
{
  "orderCode": "PB202203200003",
  "cancelReason": "手动取消"
}
```

**成功响应**:

```json
{
  "code": "200",
  "message": "",
  "sentTime": "2020-12-21 05:53:57.000"
}
```

**失败响应（波次不存在或已完结）**:

```json
{
  "code": "404",
  "message": "波次不存在或已完结",
  "sentTime": "2020-12-21 05:53:57.000"
}
```

### 3.3 代码实现

**宏定义**: [define.h:102](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/define.h#L102)

**功能说明**:

- 解析 `orderCode` 和 `cancelReason` 参数
- 校验波次号是否匹配当前活跃波次
- 安全保护：已开始分拣（`WAVE_SORTING` 及以上）的波次不允许取消
- 清理波次分拣状态集、容器绑定映射
- 响应格式与 WMS 文档 §4.2 完全一致

**代码位置**:

- 路由入口: [HttpServer.cpp:393-399](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpServer.cpp#L393-L399)
- 处理函数: [HttpServer.cpp:480-534](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpServer.cpp#L480-L534)
- 响应构建: [HttpServer.cpp:425-441](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/HttpServer.cpp#L425-L441)
- 状态机: [WaveManager::clearWave](file:///d:/WCS/WCSApp/WCS_httpServer/WCS_httpServer/WaveManager.cpp#L268-L282)

### 3.4 额外安全保护（超出 WMS 文档）

代码额外增加了波次状态校验：如果波次已进入 `WAVE_SORTING`（分拣中）状态，不允许取消。此保护在 WMS 文档中未定义，属于 WCS 侧的安全防护，防止误操作导致正在分拣的数据被意外清理。

## 四、未实现功能清单

| 序号  | 未实现项         | 说明                                                   | 影响                         |
| --- | ------------ | ---------------------------------------------------- | -------------------------- |
| 1   | **自动超时取消**   | `WaveManager` 有 `m_waveTimeoutMin` 字段，但没有定时器主动触发超时回传 | 波次超时不自动完结，需要依赖 PLC 反馈或手动回传 |
| 2   | **异常标记接口**   | 没有供 WMS 或外部系统主动标记某条码为异常的 HTTP 接口                     | 异常只能通过 PLC 反馈或内部逻辑产生       |
| 3   | **波次状态查询接口** | 没有供 WMS 查询当前波次执行状态的 HTTP 接口                          | WMS 无法查询波次分拣进度             |
